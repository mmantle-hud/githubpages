# 10.3.1 Weekly Summary

This week explored the use of database driven applications using Flask.

- The use of the _psycopg2_ library to connect to a PostgreSQL database and run queries.
- Using the results of SQL queries instead of hard-coded data to build web pages. 
- Refactoring code to remove duplicate code, separate concerns, and follow the _single responsibility principle_
