When Flask receives the request, Python code is executed that runs SQL to get results from a database.

```python
@app.route("/")
def index():
    query = "SELECT hotel_id, hotel_name FROM hotels;"
    with conn.cursor(cursor_factory=DictCursor) as cur:
        cur.execute(query)
        hotels = cur.fetchall()
    return render_template("hotels/index.html", hotels=hotels)
```

In this example, we can see an SQL query assigned to a Python variable. 

The results returned by the database are represented as Python data structures, for example a list of dictionaries.

We can generate HTML using the results from the database. 


```python
{% raw %}
    <p>Here you will find a list of Hotels in the local area</p>
    <ul>
    {% for hotel in hotels %}
        <li>
            {{ hotel['hotel_name'] }}
        </li>
    {% endfor %}
    </ul>
{% endraw %}
```

Note, this exactly the same code we used last week in the template file. 

The only difference is the data is now coming from the database.
