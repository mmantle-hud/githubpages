# Week 7 Summary of Learning

This week we looked at three important relational database topics:
- Views. A view is a saved SQL query that can be treated like a virtual table, letting you simplify complex queries or control what data users can access.
- Indexes. A data structure that speeds up data retrieval on a table.
- Transactions. How transactions, a group of database operations that either all succeed together or all fail together, can help manage concurrent database access. 

We looked at practically how to implement views and indexes in the lab sessions.
