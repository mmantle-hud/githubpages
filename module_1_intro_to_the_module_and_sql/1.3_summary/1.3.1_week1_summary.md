## Weekly Summary of Learning

In this introductory week we considered key concepts of relational databases such as data, tables, columns and rows.

We briefly covered the history of databases and the importance of Edgar F. Codd's mathematical relational model in evolving databases from brittle 1970s pointer-based models to the widely used RDBMS we use today.

In the second part of this week, SQL, the language for interacting with relational databases was introduced. 
- The main parts of the language DDL, DML, DCL, TCL.
- Using `CREATE` to create database tables
- Implementing CRUD operations using `INSERT`,`UPDATE`,`SELECT` and `DELETE`.

We also considered the importance of following clear conventions when writing our SQL code.

In the lab session we got our first hands-on experience of using PostgreSQL and SQL.
