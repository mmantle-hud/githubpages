## Coursera
### Database Design and Basic SQL in PostgreSQL (University of Michigan)
    - Some good stuff on why postgres, history of rel db, SQL etc. Mentions CRUD, math vs software engineer view of databases. Comparison of different RDMS.
    - This is also the source of the amazon choosing postgres.
    - Practically he starts with the command line - don't have to take screenshots
### Introduction to Databases - meta
    - Good for non-relational explanatations
### Relational Database Design - https://www.coursera.org/learn/relational-database-design/home/module/1
        - Uses ERD - ERM

### Introduction to Relational Databases (RDBMS) - IBM
    - Uses the ERD approach, Seems a bit mechanical.
