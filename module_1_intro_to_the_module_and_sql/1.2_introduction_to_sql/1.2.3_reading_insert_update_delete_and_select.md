#  CRUD Operations - INSERT, UPDATE, DELETE and SELECT

Once we have created our databases tables there are four fundamental actions we perform. We use the acronym CRUD to describe these operations. We'll use the example of an e-commerce website to illustrate the idea of CRUD.
- *Create* using SQL `INSERT`. This is inserting rows into a database table. For example, if a user registers on a website we need to store their details in a database.
- *Read* using SQL `SELECT`. For example, to retrieve a list of products to display on a website.
- *Update* using SQL `UPDATE`. This is editing or modifying data. For example, if an administrator needs to change the price of a product.
- *Delete* using SQL `DELETE`. This is destroying data. For example, if a user chooses to close their account, we would delete data from a database table.   

To learn about these SQL statements, we will continue the example of the `students` table. After executing our `CREATE` statement we would have an empty table like the following. 

**students**

|student_id (PK) | given_name | family_name   | degree                  | score |
|-----------|------------|---------------|-------------------------|-------|
|           |            |               |                         |       |
|           |            |               |                         |       |
|           |            |               |                         |       |
|           |            |               |                         |       |
|           |            |               |                         |       |
|           |            |               |                         |       |

## Inserting Data
To add data to a table we use an `INSERT` statement.

```sql
INSERT INTO students (given_name, family_name, degree, score)
    VALUES ('Edgar','Codd','Computing',92);
```

The table would then look like:

**students**

|student_id (PK) | given_name | family_name   | degree                  | score |
|----------|------------|---------------|-------------------------|-------|
|1         | Edgar      | Codd          | Computing               | 92    |

We specify the columns we are inserting into and the values we want to insert. 

Note, we didn't specify a `student_id` value. When we created the table we specified that PostgreSQL should generate the `student_id` number for this.

We can insert multiple rows, for example:-

```sql
INSERT INTO students (given_name, family_name, course, score) 
VALUES
('Elizabeth', 'Fong', 'Data Science', 67),
('Patricia', 'Selinger', 'Computing', 85),
('Donald', 'Chamberlin', 'Information Technology', 85),
('Michael', 'Stonebraker', 'Data Science', 34),
('Jennifer', 'Widom', 'Computing', 47);
```

**students**

|student_id (PK) | given_name | family_name   | degree                  | score |
|----------|------------|---------------|-------------------------|------|
|1         | Edgar      | Codd          | Computing               | 92   |
|2         | Elizabeth  | Fong          | Data Science            | 67   |
|3         | Donald     | Chamberlin    | Information Technology  | 85   |
|4         | Patricia   | Selinger      | Computing               | 85   |
|5         | Michael    | Stonebraker   | Data Science            | 34   |
|6         | Jennifer   | Widom         | Computing               | 47   |

Note, how PostgreSQL keeps track of `student_id` and automatically assigns the next available number. 

### Inserting Text
When inserting data we enclose strings in single quotes. However, the text we are inserting may already contain quotes. 

We can escape the quote by using an extra quote e.g. 'O''Conner'

```sql
INSERT INTO students (given_name, family_name, degree, score)
    VALUES ('Susan','O''Conner','Computing',67);
```

## Updating Data

`UPDATE` is used to modify the data in a table. For example to change a student's score:

```sql
UPDATE students
SET score = 85
WHERE student_id = 7;
```

The primary key value makes it absolutely clear which row we want to change. 

We can update multiple values in a row, for example

```sql
UPDATE students
SET
    course = 'Data Science',
    score = 92
WHERE student_id = 1;
```

We simply separate the columns to be updated with commas.

## Deleting Data

`DELETE` removes a row from a table. For example, if a student decides to leave the course:

```sql
DELETE FROM students
WHERE student_id = 1;
```

We can delete multiple rows based on a condition e.g. remove all the students that haven't passed.

```sql
DELETE FROM students
WHERE score < 40;
```

If we don't specify a `WHERE` clause all rows will be affected.

```sql
DELETE FROM students;
```
This SQL statement would delete all rows from the table!

## Selecting Data

- The most commonly used SQL statement is `SELECT`. It is used to retrieve data from the database.
- To select data we use the keyword `SELECT`, we then specify the columns we want to retrieve and finally the name of the table we want to get the data from e.g.

```sql
SELECT given_name, family_name FROM students;
```

Would result in:-

| given_name | family_name   |
|------------|---------------|
| Edgar      | Codd          |
| Elizabeth  | Fong          |
| Patricia   | Selinger      |
| Donald     | Chamberlin    |
| Michael    | Stonebraker   |
| Jennifer   | Widom         |

An asterisk can be used as a shorthand to select all columns.

```sql
SELECT * FROM students;
```

|student_id| given_name | family_name   | degree                  | score |
|----------|------------|---------------|-------------------------|------|
|1         | Edgar      | Codd          | Computing               | 92   |
|2         | Elizabeth  | Fong          | Data Science            | 67   |
|3         | Donald     | Chamberlin    | Information Technology  | 85   |
|4         | Patricia   | Selinger      | Computing               | 85   |
|5         | Michael    | Stonebraker   | Data Science            | 34   |
|6         | Jennifer   | Widom         | Computing               | 47   |

This is useful when we quickly want to test a query. We should **never** use it in production code. It is important to clearly state the data we want to retrieve for clarity and security reasons.
