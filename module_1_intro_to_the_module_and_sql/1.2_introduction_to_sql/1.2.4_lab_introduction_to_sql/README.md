# Introduction to SQL

## SQL `CREATE`

- Open _movies_schema.sql_. 
- Write an SQL statement in this file that will create a table named _movies_. The table needs to have 4 columns:
    - `movie_id`. This should be the primary key column. `movie_id` numbers should be auto-generated by PostgreSQL.
    - `title`. This will store the title for the movie.
    - `release_year`. This will store the year the movie was released.
    - `duration_in_minutes`. This will store the duration of the movie in minutes.
- Select suitable data types for each column.
- Consider which columns can be NULL.

- Click on 'Run on active connection' (it should be near the top of the file) to execute the SQL in this file. 
- VS Code should open a new editor panel to give some feedback on your query. 
- Use the SQLTools extension to explore the structure of the table you have just created. - To find the movies table you will need to open the _Coursera Labs_ connection, the _postgres_ database, and then _Schemas_, _public_, _Tables_ and finally _movies_. 

## SQL `INSERT`
- Open _movies_seeder.sql_.
- Click on 'Run on active connection' to execute the SQL in this file. Use the SQL Console to confirm this statement has executed correctly.
- To double-check, use the SQLTools extension and the 'Show Table Records' option.

- Find the details of three movies on Wikipedia. In _movies_seeder.sql_ write an additional INSERT statement that will add all three movies to your table. Check this works. 

## SQL `SELECT`
- Open _movies_queries.sql_.
- Click on 'Run on active connection' to execute the SQL in this file. The movies table should be displayed in a new editor pane. 
- Add an additional ```SELECT``` statement in _movie_queries.sql_. This should only retrieve the title and the release year for the movies in your table. 
    - If we select 'Run on active connection' VS Code will execute both queries. To only run the new query, highlight the new query, right-click and select 'Run selected query'.

## SQL `UPDATE`
- Add an ```UPDATE``` statement to your _movie_queries.sql_ file e.g. change the title or duration of a movie.  
- Check this works e.g. by running your ```SELECT``` query again. 

## SQL `DELETE`
- Add a ```DELETE``` statement to your _movie_queries.sql_ file that will remove a single movie from the table. 
- Again, check this works.
