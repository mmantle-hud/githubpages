# Introduction to SQL Solutions

## Basic CREATE (board_games_schema.sql)
```sql
CREATE TABLE board_games(
    board_game_id INT GENERATED ALWAYS AS IDENTITY,
    game_title VARCHAR(255) NOT NULL,
    release_year SMALLINT NOT NULL,
    min_age SMALLINT NOT NULL,
    min_playing_time_in_mins SMALLINT NOT NULL,
    max_playing_time_in_mins SMALLINT NOT NULL,
    min_num_players SMALLINT NOT NULL,
    max_num_players SMALLINT NOT NULL,
    CONSTRAINT pk_board_games PRIMARY KEY (board_game_id)
);
```
## INSERT (board_games_seeder.sql)
```sql
INSERT INTO board_games (
        game_title,
        release_year,
        min_age,
        min_playing_time_in_mins,
        max_playing_time_in_mins,
        min_num_players,
        max_num_players
    )
VALUES ('Carcassonne', 2000, 7, 30, 45, 2, 5),
    ('Scrabble', 1948, 8, 60, 90, 2, 4),
    -- For Ticket to Ride set the wrong year, fix it later with UPDATE
    ('Ticket to Ride', 2014, 8, 30, 60, 2, 5);
```
## SELECT, UPDATE and DELETE (board_games_queries.sql)
```sql
-- Select the title and year of release
SELECT game_title,
    release_year
FROM board_games;

-- Update Ticket to Ride
UPDATE board_games
SET release_year = 2004
WHERE board_game_id = 4;

-- Delete Scrabble
DELETE FROM board_games
WHERE board_game_id = 3;
```

## Optional Extra
- Adding constraints to the ```CREATE``` statement in _board_games_schema.sql_.

```sql
CREATE TABLE board_games(
    board_game_id INT GENERATED ALWAYS AS IDENTITY,
    game_title VARCHAR(255) NOT NULL,
    release_year SMALLINT NOT NULL,
    min_age SMALLINT NOT NULL,
    min_playing_time_in_mins SMALLINT NOT NULL,
    max_playing_time_in_mins SMALLINT NOT NULL,
    min_num_players SMALLINT NOT NULL,
    max_num_players SMALLINT NOT NULL,
    CONSTRAINT pk_board_games PRIMARY KEY (board_game_id),
    CONSTRAINT chk_min_age CHECK (min_age >= 0),
    CONSTRAINT chk_player_count CHECK (max_num_players >= min_num_players),
    CONSTRAINT chk_min_players CHECK (min_num_players > 0),
    CONSTRAINT chk_playing_time CHECK (max_playing_time_in_mins >= min_playing_time_in_mins),
    CONSTRAINT chk_min_time CHECK (min_playing_time_in_mins >= 0)
);
```
