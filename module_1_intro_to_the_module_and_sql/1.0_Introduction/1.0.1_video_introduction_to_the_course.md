# Introduction to the Course







Welcome to Relational Databases and Web Integration. In this course we will explore the most widely used form of database in the world, the relational database. Broadly speaking the course has two parts; a relational database part and a web integration part. In the first part of the course we will learn about relational databases from the ground up exploring key concepts such as tables, constraints and relationships. Alongside this theory, we will also explore SQL, the programming language we use to interact with databases. Initially, we will work with single tables and develop fundamental skills such as creating tables, querying databases, filtering results, and performing aggregations. We will then go on to work with more complex databases where there are relationships, and we'll use SQL joins to retrieve data from multiple tables. Once we have this fundamental knowledge in place, and around the midway point of the course, we will cover the important topic of database design. How to decide what tables we need in a database, and how to design our tables so we reduce the possibility of duplicate data and ensure our data is accurate and correct. The final modules in the first part of the course will explore more advanced queries involving outer joins and subqueries. We will also consider how to speed up queries using indexes, and how to deal with complexity using views and transactions. The second, shorter part of the course is about web application development using relational databases. We will learn how to create basic web pages using HTML and Cascading Style Sheets. We will then move on to develop database driven web applications using the Flask framework. Finally, in the last week of the course, we will review what we have learnt, and compare relational databases to other types of database such as NoSQL databases.
