# Overview of Assessment
There are three pieces of assessment in the module

## Database Design Report (1200 words) (30%)
- Hand-out: Week 4
- Hand-in: 26th October 2026 (Week 7)

You will be given a scenario that describes requirements for a relational database. You will then produce a document that uses entity relation diagrams (ERDs) to specify the design of a database that will fulfill these requirements. Alongside the diagrams you will produce an analysis for the design choices you have made. 

## Database Driven Web Application Report (2000 words) (50%)
- Hand-out: Week 8
- Hand-in: 7th December 2026

You will build a web application using the Python Flask framework that dynamically builds webpages using data from a PostgreSQL relational database. You will then write a report that documents the development you have undertaken, and explains and analyses the choices made in building the app. 

## Online Quiz (20%)
- The quiz will take place on the 11th December 2026

The 1-hour quiz will test your understanding of the course contents.
