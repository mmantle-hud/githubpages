# Introduction to Flask

## How Does the WWW Work?

The following sequence diagram shows the basic way in which the WWW works. 

<pre class="mermaid">
%%{init: { "sequence": { "mirrorActors": false } } }%%
sequenceDiagram
    actor User
    participant Browser
    participant Server

    User->>Browser: Click link / enter URL

    Browser->>Server: GET /
    Server-->>Browser: index.html

    Note over Browser: Parse HTML
    Note over Browser: Discover styles.css

    Browser->>Server: GET /styles.css
    Server-->>Browser: styles.css

    Note over Browser: Apply CSS rules

    Browser-->>User: Display styled webpage
</pre>

Users click on a link or enter a URL to specify a web page they'd like to access. 

The browser sends out a request for the page over the internet to a web server. 

The server receives the request and sends the page to the browser. 

The browser reads (parses) the HTML document, if there are further links e.g. to a CSS file or image files, the browser makes further requests.

The browser then applies the CSS rules, inserts images, and displays the page for the user. 

This basic model assumes our HTML pages are **static** i.e. they don't change once we've created them. All the pages we created last week were static pages. 

Most real world web pages are **dynamic**. The content of the page is generated when the server receives the request.

Now, when the request is made to the server, the server passes the request onto a server-side programming language e.g. Python, PHP, Java, C#.

Code is executed that generates a HTML page.

This HTML page is sent back to the browser, where the page can be displayed for the user. 

## A First Look at Flask Code?
Different server-side programming languages and frameworks do things differently. We will use Python and the Flask framework. 

A **framework** is simply code someone else has written (3rd party code) that we can use as a starting point for building our own web applications. 

We might have some data in our app e.g. a list of python dictionaries:

```python

hotels = [
    {
        "hotel_id": 1,
        "hotel_name": "The Grand House",
        "price": 249.99,
        "star_rating": 5,
        "distance_to_centre_kms": 0.40,
    },
    {
        "hotel_id": 2,
        "hotel_name": "Urban Nest",
        "price": 115.50,
        "star_rating": 4,
        "distance_to_centre_kms": 1.85,
    },
    {
        "hotel_id": 3,
        "hotel_name": "Metro Plaza Hotel",
        "price": 140.00,
        "star_rating": 4,
        "distance_to_centre_kms": 0.80,
    }
]
```

We could then dynamically generate HTML using this data


```python
{% raw %}
    <p>Here you will find a list of Hotels in the local area</p>
    <ul>
    {% for hotel in hotels %}
        <li>
            {{ hotel['hotel_name'] }}
        </li>
    {% endfor %}
    </ul>
{% endraw %}
```
The pair of double curly brackets `{{...}}` is a placeholder, this gets filled by output from Python code before the page is sent to the user.

{% raw %}`{% for hotel in hotels %}`{% endraw %} and {% raw %}`{% endfor %}`{% endraw %} allow us to insert a Python `for` loop into our HTML document. 

This code would generate the following HTML. Which would be sent back to the browser. 

```html
<p>Here you will find a list of Hotels in the local area</p>
<ul>
<li>The Grand House</li>
<li>Urban Nest</li>
<li>Metro Plaza Hotel</li>
</ul>
```

The key point is plain HTML is sent to the web browser. Web browsers only understand HTML, CSS and JavaScript. They don't understand Python code. 


In the lab sessions we will gain a much deeper understanding of how Flask works.

## Why Make Pages Dynamic?

The idea is a single URL, but different content is served. 

For example, a search facility in a web application. The user enters a search term and clicks submit. 

Different HTML will be returned depending on the search term the user entered.
