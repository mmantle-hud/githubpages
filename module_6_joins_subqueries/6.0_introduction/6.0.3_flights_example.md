# Flights Database
This database will be used as the basis for the labs this week. Have a quick look at it now, and then refer back to this page to help you answer the questions presented in the lab sessions this week. 
 
The following database stores data about flights for an airline. You should be able to make sense of the database based on the ERD and example tables but there are a couple of points worth noting:-

- `airports` uses a natural key (`iata_code`) e.g. LHR for London Heathrow.
- `aircraft` also uses a natural key `tail_number` e.g. G-TTNB. 
- `flights` features a number of nullable columns. This is because the aircraft to be used and the price of the flight might not be known when the flight is first created. These details can be added later.

    airports {
        CHAR(3) iata_code PK
        VARCHAR(255) name "NOT NULL"
        VARCHAR(100) city "NOT NULL"
        SMALLINT number_runways "NOT NULL"
    }

    routes {
        INT route_id PK
        CHAR(3) origin_airport FK "NOT NULL"
        CHAR(3) destination_airport FK "NOT NULL"
        INT distance_km "NOT NULL"
    }

    aircraft {
        VARCHAR(10) tail_number PK
        INT model_id FK
    }

    aircraft_models {
        INT model_id PK
        VARCHAR(255) manufacturer "NOT NULL"
        VARCHAR(255) model_name "NOT NULL"
        INT seat_capacity "NOT NULL"
    }

    flights {
        INT flight_id PK
        INT route_id FK  "NOT NULL"
        VARCHAR(10) tail_number FK  "NULL"
        TIMESTAMP departure  "NOT NULL"
        TIMESTAMP arrival  "NOT NULL"
        DECIMAL base_price "NULL"
    }
</pre>
