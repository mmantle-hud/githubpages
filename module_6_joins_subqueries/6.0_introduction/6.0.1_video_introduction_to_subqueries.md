# Introduction to Week 6

This week we return to writing SQL queries. Building on the content we covered in the first three modules we will go deeper into SQL by looking at subqueries, outer joins and common table expressions.   

A subquery is a query within another query. Sounds complicated? Well many people do find subqueries challenging to understand. However, we will build up examples in steps and hopefully provide a clear introduction to this important SQL skill. 

So far we have only used inner joins when querying multiple tables. This week we will also look at some different types of join, left, right and full outer joins. 

The last topic we will look at is common table expressions or CTEs. CTEs allow us to break down large queries into smaller more manageable parts. They are a technique we can use to help us manage large, complex queries. 

There's a lot to work through this week, but if you can master these important topics, you will be in a strong position for the second assessment, and any SQL tasks you encounter in the future.
