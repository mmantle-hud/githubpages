# Week 6 Summary of Learning

- This week we looked at more complex joins.
    - Subqueries
    - Scalar subqueries
    - Multiple rows, single value subqueries
    - Table Subqueries in the FROM Clause (Derived Tables)
    - Outer Joins
    - LEFT and RIGHT outer joins
    - Common Table Expressions (CTEs)
- We also considered how these types of when and when each type of query should be used.
- There were three labs were we practiced each type of query using a flights database.
