# Preparing for the Final Assessment

The final assessment is a quiz.

The quiz will be open for a 48-hour window from 12:00PM 10th December 2026- 12:00PM 12th December 2026. The quiz will appear under 12.3.2 Final Assessment Quiz.

The quiz questions will test your understanding of the content we covered in **modules 1-7** and **module 11**. 

There will be **no** questions about Modules 8,9 and 10 where we covered web development using Flask. 

You get 1 hour to complete the quiz. 

You get a **single** attempt. So make sure you have prepared beforehand. 

There will be a mixture of multiple choice and multi-answer questions.

- Each multiple choice question is worth 1 point.

- Each multi-answer question is worth 2 points. You need to select all the correct answers and none of the incorrect answers to get the points.
