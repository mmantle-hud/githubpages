# Aggregate Functions, GROUP BY and SQL Functions

All the queries we have run so far retrieve raw data exactly as it appears in the table. Aggregate functions and the ```GROUP BY``` statement allow us to manipulate the data before we display it. 

Again, we'll use the _students_ table example to demonstrate aggregate functions and ```GROUP BY```.

|5         | Michael    | Stonebraker   | Data Science            | 34   |

## Aggregate Functions
Aggregate functions perform an action over multiple rows.

```sql
SELECT COUNT(*) AS total_num_students FROM students;
```

| total_num_students | 
|--------------------|
| 6                  |


- ```COUNT()``` counts the number of rows. The asterisk (*) means select all rows. 
- `AS` is a keyword used to specify an alias i.e. the result of `COUNT(*)` will be presented in a column named `total_num_students`. The use of `AS` is completely optional. We do it to generate cleaner, more understandable column names. It is widely used when writing ```SELECT``` queries. 

    <!-- - We could specify a column e.g. `COUNT(score)`. However, this ignore columns with NULL for score.  -->

There are other aggregate functions we can use e.g. ```MAX```, ```MIN```, ```AVG```, ```SUM```

```sql
SELECT AVG(score) AS average_score FROM students;
```

| average_score       | 
|--------------------|
| 68.3333333333333333|


## GROUP BY
We can group rows together

```sql
SELECT degree
FROM students
GROUP BY degree;
```

| degree                  |
|-------------------------|
| Data Science            |
| Information Technology  |
| Computing               |


All the rows with the same degree value are combined into a single row. Note, this achieves the same result as using the `DISTINCT` keyword we looked at previously.

## Grouping and Aggregating
Grouping becomes powerful when we use it with aggregate functions.

```sql
SELECT degree, COUNT(*) AS number_of_students 
FROM students
GROUP BY degree;
```

| degree                  |number_of_students|
|-------------------------|------------------|
| Data Science            |2                 |
| Information Technology  |1                 |
| Computing               |3                 |


The ```COUNT``` function is applied to each group telling us the number of students on each degree. Here's another example that tells us the average score for each degree.  

```sql
SELECT degree, AVG(score) AS average_score 
FROM students
GROUP BY degree;
```

| degree                  |average_score      |
|-------------------------|------------------|
| Data Science            |50.50000000000000 |
| Information Technology  |85.00000000000000 |
| Computing               |74.66666666666667 |


When using ```GROUP BY``` any column that appears in your ```SELECT``` clause must meet one of two conditions. Either it must be listed in the ```GROUP BY``` clause **or** it is wrapped inside an aggregate function.

If you try to select an unaggregated column that is not in the ```GROUP BY``` clause PostgreSQL will reject the query and throw an error.

## Having
- We can apply filter conditions **after** the grouping has taken place using ```HAVING```.

```sql
SELECT degree, AVG(score) AS average_score 
FROM students
GROUP BY degree
HAVING AVG(score) > 70;
```

| degree                  |top_score          |
|-------------------------|------------------|
| Information Technology  |85.00000000000000 |
| Computing               |74.66666666666667 |


## Grouping, Aggregating and NULL
Imagine Jennifer Widom didn't submit any assignments. How would this NULL value affect our aggregate calculations?

|student_id (PK) | given_name | family_name   | degree                  | score |
|----------------|------------|---------------|-------------------------|-------|
|1               | Edgar      | Codd          | Computing               | 92    |
|2               | Elizabeth  | Fong          | Data Science            | 67    |
|3               | Patricia   | Selinger      | Computing               | 85    |
|4               | Donald     | Chamberlin    | Information Technology  | 85    |
|5               | Michael    | Stonebraker   | Data Science            | 34    |
|6               | Jennifer   | Widom         | Computing               | NULL  |

<p></p>    
```sql
SELECT COUNT(*) AS num_rows, COUNT(score) AS num_rows_with_a_score, AVG(score) AS avg_score FROM students;
```

|num_rows| num_rows_with_a_score | avg_score   | 
|--------|----------------------|------------|
|6       | 5                    | 72.60000000|


`COUNT(*)` counts all rows, even if they have a NULL value. 

Aggregate functions ignore NULL values!
- `COUNT(score)` only counts rows where the score isn't NULL. 
- `AVG(score)` only considers rows where the score isn't NULL (72.6 = (92+67+85+85+34)/5). We divide by 5, not 6! We'll look at how to fix this problem shortly.

## Grouping Over Multiple Columns
Consider the following table that records the sales made at various branches of a chain of coffee shops.


| branch     | product          | product_category | price  |
| :----------| :--------------- | :--------------- | :----- |
| Central    | Latte            | Drinks           | 3.00   |
| Central    | Espresso         | Drinks           | 2.50   |
| Central    | Carrot Cake      | Food             | 3.50   |
| New Street | Blueberry Muffin | Food             | 2.75   |
| New Street | Espresso         | Drinks           | 2.50   |
| New Street | Americano        | Drinks           | 2.70   |


We might want to know the total sales generated for each category.

```sql
SELECT 
  product_category, 
  SUM(price) AS total_sales
  FROM sales
GROUP BY product_category;
```

| product_category |total_sales|
|------------------|-----------|
| Food             |6.25       |
| Drinks           |10.70      |


We might want to go a step further and know the total sales generated for each category in each branch. To do this we can use multi-column grouping. 

```sql
SELECT 
  branch,
  product_category, 
  SUM(price) AS total_sales
  FROM sales
GROUP BY branch, product_category;
```

| branch     | product_category | price  |
| :----------| :--------------- | :----- |
| Central    | Drinks           | 5.50   |
| Central    | Food             | 3.50   |
| New Street | Food             | 2.75   |
| New Street | Drinks           | 5.20   |


## Some Other SQL Functions
Here are some additional functions that are useful for us when writing SQL.

### ROUND
We can round numbers.

```sql
SELECT ROUND(AVG(score),2) AS average_score FROM students;
```

| average_score       | 
|--------------------|
| 68.33              |


The score has now been rounded to two decimal places. 

### CONCAT
- `CONCAT` is used to join strings together into a single column

```sql
SELECT 
  CONCAT(given_name,' ',family_name) AS full_name, 
  degree, 
FROM students;
```

| full_name           | degree                  |
|---------------------|-------------------------|
| Edgar Codd          | Computing               |
| Elizabeth Fong      | Data Science            |
| Patricia Selinger   | Computing               |
| Donald Chamberlin   | Information Technology  |
| Michael Stonebraker | Data Science            |
| Jennifer Widom      | Computing               |


## COALESCE
The `COALESCE` function is used to select a value from a list. To show this, we'll go back to the example where Jennifer Widom has a value of NULL for `score`. 

|student_id(PK)| given_name | family_name   | degree                  | score |
|----------|------------|---------------|-------------------------|------|
|1         | Edgar      | Codd          | Computing               | 92   |
|2         | Elizabeth  | Fong          | Data Science            | 67   |
|3         | Patricia   | Selinger      | Computing               | 85   |
|4         | Donald     | Chamberlin    | Information Technology  | 85   |
|5         | Michael    | Stonebraker   | Data Science            | 34   |
|6         | Jennifer   | Widom         | Computing               | NULL |


To use `COALESCE` We specify a list of values, the `COALESCE` function moves from left to right and uses the first non-null value it finds. 

```sql
SELECT 
  CONCAT(given_name,' ',family_name) AS full_name, 
  COALESCE(score,0) AS score
  FROM students;
```

| full_name           | score    |
|---------------------|---------|
| Edgar Codd          | 92      |
| Elizabeth Fong      | 67      |
| Patricia Selinger   | 85      |
| Donald Chamberlin   | 85      |
| Michael Stonebraker | 34      |
| Jennifer Widom      | 0       |


Jennifer Widom's NULL value has been replaced with zero.

- We can use `COALESCE` in an aggregate function e.g.

```sql
SELECT ROUND(AVG(COALESCE(score, 0)), 2) AS average_score_for_course
FROM students;
```

| average_score_for_course       | 
|--------------------|
| 60.50  |


Using a combination of the `AVG`, `COALESCE` and `ROUND` functions we can now get the overall average score for the course, and present it neatly.
