# Grouping and Aggregate Functions Solutions
```sql
-- 1) Display the total number of board games in the database
SELECT COUNT(*) AS total_num_games
FROM board_games;

-- 2) Display the average maximum playing time (rounded to the nearest minute) of all the board games in the database.
SELECT ROUND(AVG(max_playing_time_in_mins), 0) AS average_max_playing_time
FROM board_games;

-- 3) Display the lowest value for minimum playing age in the database.   
SELECT MIN(min_age) AS lowest_min_age
FROM board_games;

-- 4) Display the average maximum playing time (rounded to the nearest minute) of all the board games released in the 21st century
SELECT ROUND(AVG(max_playing_time_in_mins), 0) AS average_max_playing_time
FROM board_games
WHERE release_year > 2000;

-- 5) Display each year and the number of games released in that year
SELECT release_year,
    COUNT(*) AS num_of_games
FROM board_games
GROUP BY release_year;

-- 6) Display each year and the number of games made in that year. Sort the results by the number of games in descending order. 
SELECT release_year,
    COUNT(*) AS num_of_games
FROM board_games
GROUP BY release_year
ORDER BY num_of_games DESC;

-- 7) Display each release year, the number of games released that year, and the average maximum playing time (rounded to the nearest minute) of those games.
SELECT release_year,
    COUNT(*) AS number_of_games,
    ROUND(AVG(max_playing_time_in_mins), 0) AS avg_playing_time
FROM board_games
GROUP BY release_year;

-- 8) Modify the query to only show years where more than a single game was released.
SELECT release_year,
    COUNT(*) AS number_of_games,
    ROUND(AVG(max_playing_time_in_mins), 0) AS avg_playing_time
FROM board_games
GROUP BY release_year
HAVING COUNT(*) > 1;

-- 9) For all the games that are suitable for people aged less than 10 display the game title and release year in the format 'game_title (release_year)'' e.g. Carcassonne (2000)
SELECT CONCAT(game_title, ' (', release_year, ')') AS title_and_year
FROM board_games
WHERE min_age < 10;

-- 10) Display each release year, the number of games released in that year, and the longest minimum playing time. Only display years where at least 2 games were released. Sort the results by the number of games released, from highest to lowest.
SELECT release_year,
    COUNT(*) AS number_of_games,
    MAX(min_playing_time_in_mins) AS longest_min_playing_time
FROM board_games
GROUP BY release_year
HAVING COUNT(*) >= 2
ORDER BY number_of_games DESC;
```
