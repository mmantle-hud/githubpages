# Week 3 Summary of Learning
This week we introduced how relationships between entities are represented in relational databases in both one-to-many relationships and many-to-many relationships.
- Cardinality and optionality, parent and child tables, how foreign keys are used to connect related tables, how many-to-many relationships require a junction table. 
- Using SQL inner joins to retrieve data from multiple tables.
- Other types of relationship: one-to-one and self relationships.  

We also had our first look at ERDs, including how they represent keys, data types, cardinality, and optionality.
