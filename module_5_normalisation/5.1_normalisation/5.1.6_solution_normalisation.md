# Exercise: Normalising the Community College Enrolments Database
A small college offer courses to people living in the local community. If local residents sign-up and pay a small annual fee they can become members, this allows them to book onto two courses a year. Optionally, residents can take out 'gold' membership which allows them to book onto an unlimited number of courses. Many courses require members to bring their own equipment e.g. a table tennis bat is needed for table tennis, a laptop for the creative writing course.   

They have a simple database that keeps track of the different courses they offer, the equipment needed and who has enrolled on which course.

For each normalisation step you should produce a logical ERD and example tables. 

You can produce hand drawn ERDs and tables for this exercise. You should spend your time thinking about normalisation, not creating neat, perfect diagrams. 

## Solution

- Remove multiple values in the equipment column. 
- Make a composite PK (`member_id`, `course_code`, `equipment`)

### 3NF
There is a transitive dependency. `annual_fee` is dependent on `membership_type`. Therefore, we create a separate `membership` table.


<pre class="mermaid">
erDiagram
    accTitle: Physical ERD for the Community College Database.
    accDescr: Physical ERD for the Community College Database.
    enrolments}o--||members : ""
    enrolments}o--||courses : ""
    course_equipment}|--||courses: ""
    members}|--||memberships : ""
    enrolments {
        INT member_id PK
        INT course_code PK
    }
    members {
        INT member_id PK
        VARCHAR(255) given_name "NOT NULL"
        VARCHAR(255) family_name "NOT NULL"
        INT membership_id FK
    }
    memberships {
        INT membership_id PK
        VARCHAR(255) membership_type "NOT NULL"
        NUMERIC annual_fee "NOT NULL"
    }
    courses {
        INT course_code PK
        VARCHAR(20) course_name "NOT NULL"
        date start_date "NOT NULL"
        date end_date "NOT NULL"
    }
    course_equipment{
        INT course_code PK, FK
        VARCHAR(255) equipment PK
    }
</pre>
