# Hyperlinks and Images

## Hyperlinks
A link is a connection from one web resource to another HTML page, an image, an audio file, a video file etc.

There is only one tag responsible for linking documents, the anchor element `<a>`. The `<a>` tag works just like any other tag `<p>`, `<h1>` etc.

```html
<a href="http://www.hud.ac.uk">Link to Huddersfield University homepage</a>
```
- The `href` attribute specifies the URL of the page that the user will link to.
- 
<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: white; padding: 10px;">
<a href="http://www.hud.ac.uk" style="color:black">Link to Huddersfield University homepage</a>
</div>

There are two types of URL, absolute URLs and relative URLs. Absolute URLs specify the complete address of a
web resource e.g. `http://www.hud.ac.uk` or `D:/website/index.html`.

Absolute URLs should be used when linking to a separate website. For linking pages together in the same website we should
use relative URLs

Relative URLs specify the location of a web resource relative to the current document's location.

```html
<a href="/portfolio/example1.html">Example 1</a>
```

This link uses a relative URL instructing the browser to look in the same directory as the current document for a page called `example1.html` in a directory called `portfolio`.

### The `<nav>` Element
Websites usually feature a navigation bar. Typically, this is structured as a list of hyperlinks and we use the `<nav>` element to indicate the collection of links is a navigation bar. 

```html
<nav>
<ul>
<li><a href="careers.html">Careers</a></li>
<li><a href="news.html">News</a></li>
<li><a href="about.html">About</a></li>
<li><a href="contact.html">Contact Us</a></li>
</ul>
</nav>
```

<nav>
<ul>
<li><a style="color:black" href="careers.html">Careers</a></li>

<li><a style="color:black" href="contact.html">Contact Us</a></li>
</ul>

This has no visual effect on the appearance of the list. Instead, we can use CSS is used to change the appearance of lists to make the hyperlinks
appear like navigation buttons.

```css
nav ul {
  list-style: none; /* remove bullets */
  padding: 0;
  margin: 0;
  display: flex; /* place items in a row */
  gap: 5px; /* space between links */
}

nav a {
  display: inline-block;      /* allows padding + background */
  padding: 3px;
  background: #e0e0e0;        /* light grey button */
  color: #333;
  text-decoration: none;
  border-radius: 4px;         /* soft rounded corners */
  font-weight: bold;
  border: 1px solid #ccc;     /* subtle button border */
}

nav a:hover {
  background: #d0d0d0;        /* slightly darker on hover */
  border-color: #999;
}
```

## Images
There is a single tag `<img>` that is responsible for inserting images into an HTML document. 

```html
<img src="images/logo.svg" alt="university logo">
```
The browser will request the image file and insert it into the HTML page. 

<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: #123482; padding: 10px;">
<img src="logo.svg" alt="university logo">
</div>

-  `<img>` is a void element. There is no closing tag.
- The `src` attribute specifies the URL of the image.
- The `alt` attribute specifies alternative text. This is used to describe the image for visually impaired users who won't be able to see the image. We should always include an `alt` attribute.

- There are a wide range of images that can be used on the web e.g. PNG, JPEG, WebP, AVIF, SVG etc.

-See https://developer.mozilla.org/en-US/docs/Web/Media/Formats/Image_types for advice on selecting a suitable image file type.
