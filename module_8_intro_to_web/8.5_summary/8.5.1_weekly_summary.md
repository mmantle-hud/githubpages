# Week 8 Summary of Learning

This week has been a brief introduction to HTML and CSS. We have covered
- HTML
  - Basic principles of HTML: elements, nesting, attributes, void element.
  - Text-related tags
  - Document structure
  - Hyperlinks
  - Inserting Images
- CSS
  - Basic principles of CSS: CSS rules, selector and declarations
  - Text-related properties
  - Box properties
  - CSS UNits

There are lots of topics we haven't covered e.g.
- HTML tables
- Inserting audio and video in HTML
- HTML forms
- Page layout using CSS
- Responsive web design and designing for mobile devices.

Some of these topics (e.g. HTML tables, page layout) might be useful for the second assignment. 

However, it isn't necessary to investigate these topics unless you are interested. 

You can score an A grade for the assessment simply by demonstrating your understanding of the content we have looked at this week.
