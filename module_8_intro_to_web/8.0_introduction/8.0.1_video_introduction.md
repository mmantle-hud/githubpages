# Introduction to Week 8. 

Hi, welcome to the second part of the module, where we will look at web application development and build database driven web applications. 

This part of the course is shorter, just three modules. 

In this first week, we will learn about the basic languages, HTML and CSS, that are used to build web pages. 

We will learn to create and style pages, insert images and link pages together. 

We will also onsider the important topic of accessibility and consider best practices when creating web pages.

The two weeks that follow will build on this knowledge and explore the Flask Web Application framework. 

A framework is simply code that someone else has written and we can use as a starting point for building our own applications.

Flask is written in the Python language that you will be familar with from previous courses and we will use Flask to integrate data from a PostgreSQL database into our web pages. 

# Introduction to Week 9

Hi, now we know about the basics of how to create and style web pages, we will move onto to building dynamic web applications using the Flask framework.

By dynamic web applications I mean web pages where the HTML content is generated using Python code. 

In this first week on Flask, we will learn about routing, view functions and templates, and we will build basic dynamic pages.

You will find there's not much reading this week. 

I'm a firm believer that the best way to learn a technology such as Flask is with a more hands-on approach where you run code and see the results. Therefore the labs are where most of the learning will take place. 

Each bit of code we use will be explained, take your time to work through the examples, and attempt the additional activities.

If you do get stuck or can't complete the lab, don't worry. A working solution to the lab work will be used as the starting point for the lab that follows. 

In this way there will always be a solution you can look at. 

# Introduction to Week 10

Hi, welcome to the second part of our look at building web applications using Flask.

This week we will focus on building database driven web applications. Instead of hard-coding the data into the application, we will dynamically create pages using data from a PostgreSQL database. 

At the end of this week we will be building web applications that function like real world apps. 

Beyond the idea of integrating database content, we will also consider best practices in terms of how to write our code. 

We will look at re-factoring our code. This means re-writing it to remove duplication, and structure and organise it more effectively. 

We will consider strategies and design patterns we can use to re-write in our code as our app becomes more complex.
