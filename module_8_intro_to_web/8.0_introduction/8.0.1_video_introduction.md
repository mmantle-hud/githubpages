# Introduction to Week 8. 

Hi, welcome to the second part of the course, where we will look at web development and building database driven web applications. 

So far we have used PostgreSQL in isolation, just as a database. This second part of the course is really important as we will learn how relational databases can be used to build software applications. Specifically, web applications. 

This part of the course is shorter, just three modules. 

Because of these time constraints, we won't be able to go too deep into the topic of web development, but we will learn the basics of web page construction and we will gain useful experience in Flask, which is a widely used and industry relevant web application framework. 


In this first week, we will learn about the basic languages that are used to build web pages, HTML and CSS. 

We will learn to create and design pages, insert images and link pages together. 

We will also consider the important topic of accessibility and consider best practices when creating web pages.


# Introduction to Week 9

Hi, now we know about the basics of how to create and style web pages, we will move on to building dynamic web applications using the Flask framework.

A framework is simply code that someone else has written that we can use as a starting point for building our own applications.

Flask is written in the Python language that you will be familar with from previous courses.

In this first week on Flask, we will learn about routing, view functions and templates, and we will develop a basic dynamic web application.

You will find there's not much reading this week. 

I'm a firm believer that the best way to learn a technology such as Flask is with a more hands-on approach where you run code and see the results. Therefore the labs are where most of the learning will take place. 

Each bit of code we use will be explained, take your time to work through the examples, and attempt the additional activities.

If you do get stuck or can't complete the lab, don't worry. A working solution to the lab work will be used as the starting point for the lab that follows. 

In this way there will always be a solution you can look at. 

# Introduction to Week 10

Hi, welcome to the second part of our look at building web applications using Flask.

This week we will focus on building database driven web applications. Instead of using hard-coded data in our app, we will dynamically create pages using data from a PostgreSQL database. 

At the end of this week we will be building web applications that function like real world apps. 

Beyond the idea of integrating database content, we will also consider good practices in terms of how to write our code. 

We will look at re-factoring our code. This means re-writing it to remove duplication, and structure and organise it more effectively.

Again, if you do get stuck or can't complete the lab, don't worry. 

A working solution to the lab work will be used as the starting point for the lab that follows, 

a working version of the final lab will also be provided and should provide a good example that you could use as a basis for the assignment. 

# Introduction to Week 11

Hi, welcome to the final week of content for the course. 

This week I want us to look at a two things. 

First, although I think we have done a thorough job covering the subject of relational databases, it is worth giving some consideration to topics we haven't had time to fit into the course, and you might want to explore in your own time. So we'll briefly look at topics such as full text searching and database security. 

Second, I'd like us to compare the relational model that we have learnt about to different types of database. Here we will think about the potential limitations or disadvantages of relational databases and consider alternative types of database such as document databases and graph databases.  

There's not a huge amount of content to work through here. This should give you plenty of time to work on the second assignment and prepare for the quiz.
