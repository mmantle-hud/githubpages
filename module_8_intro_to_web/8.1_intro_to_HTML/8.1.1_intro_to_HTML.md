# Introduction to HTML

## What is HTML?
Hypertext Markup Language (HTML) is the basic language used to create web pages. When we use a web browser e.g. Chrome, Firefox, Safari, Edge and browse the web, the content we are viewing has been written using HTML. 

In a browser, if we 'right-click' on a webpage and select 'View Page Source' we can see the HTML code that was used to construct the page. Try it now with this webpage to see the underlying HTML code.

We call HTML files documents or (web)pages and we save them with a .html file extension.

## Elements

HTML document are made up of elements. Here's an example element:

```html
<h1>Welcome to HTML</h1>
```
An element usually has:
- An opening tag (`<h1>`)
- A closing tag (`</h1>`)
- Content (`Welcome to HTML`)

- The tags are instructions to the browser and not visible to the user. 
- Content is the words and images the user sees.
  
In this example the `<h1>` tag states the content is a heading. Therefore, the browser displays content on its own line and makes the text large and bold. Here's what the element would look like (_rendered_) in a browser.

<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: white; padding: 10px;">
  <h1 style="font-family: serif; color: black;">Welcome to HTML</h1>
</div>



## Nesting
Elements can be placed inside other elements. 

```html
<h1>Welcome <em>to</em> HTML</h1>
```

<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: white; padding: 10px;">
  <h1 style="font-family: serif; color: black;">Welcome <em>to</em> HTML</h1>
</div>

In this example there are two elements, an `<em>` element and an `<h1>` element. The `<em>` element has been placed inside the `<h1>` element. 

`<em>` stands for emphasis. Browsers render the content in italics.

The word 'to' is contained by both the `<em>` element and the outer `<h1>` element. As a result, not only is it displayed big and bold (from the `<h1>`), but also in italics (from the `<em>`). 

We say the `<em>` element has been nested inside the `<h1>` element. 

We can have several levels of nesting. Here's a complete HTML document.

```html
<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <title>Example HTML Document</title>
  </head>
  <body>
    <h1>Welcome to HTML</h1>
    <p>In this week we will be learning:</p>
    <ul>
        <li>HTML</li>
        <li>CSS</li>
    </ul>
  </body>
</html>
```
In this example, the element `<li>CSS</li>` is nested inside several elements `<html>` $\rightarrow$ `<body>` $\rightarrow$ `<ul>` $\rightarrow$ `<li>CSS</li>`. 
 
Nested elements must not overlap, for example the following would be incorrectly structured HTML

```html
<h2>Welcome <em>to HTML</h2></em>
```
The closing `</em>` tag comes after the closing `</h1>`. It isn't clear which element is the parent element and which is the child (nested) element. 
 
## Empty (Void) Elements
Not all elements have content. Empty, or void elements specify standalone features on an HTML page.

```html
<p>This is a paragraph</p>
<hr>
<p>Here's another paragraph</p>
```

<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: white; padding: 10px;">
<p>This is a paragraph</p>
    <hr style="display: block; border: none; border-top: 1px solid #767676; margin: 0.5em auto; width: 100%;">
<p>Here's another paragraph</p>
</div>

In this example, the `<hr>` element doesn't contain any content, and there isn't a closing tag. Instead the `<hr>` element creates a standalone feature, a horizontal rule, a line that stretches across the page. 

There are other void elements e.g. `<img>`, `<br>`, `<link>`, `<input>`. 

## Attributes
Attributes define additional information for an element.

```html
<a href="http://www.hud.ac.uk">Link to Huddersfield University homepage</a>
```
- The anchor element `<a>` is used to create a hyperlink. 
- Inside the opening tag is an attribute (`href`) that specifies the URL (web address) the text will link to (`http://www.hud.ac.uk`).
  - We separate the tag name from the attribute with a space.
  - Attributes always have the same structure `attribute="value"`.
  - An element can feature multiple attributes e.g. `<input id="given_name" type="text">`.

- `<strong>` is usually rendered in bold.

## Block vs Inline Elements
By default, when a browser renders elements such as `<p>` and `<h1>`, a newline is placed before and after the element. We call this type of element a **block level** element. 

When a browser displays elements such as `<em>` and `<strong>`, it doesn't put a line break before or after. We call this type of element an **inline** element. Generally, inline elements should always be nested inside block level elements. 

> When we look at CSS, we will see that we can override the default styling of web browsers, to apply our own styling to pages. 

## Document Structure
Every well-structured HTML page should feature key tags that provide important metadata and a structure to the document. 

Here's a complete HTML document. 

```html
<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <title>Example HTML Document</title>
  </head>
  <body>
    <h1>Welcome to HTML</h1>
    <p>In this week we will be learning:</p>
    <ul>
        <li>HTML</li>
        <li>CSS</li>
    </ul>
  </body>
</html>
```
- The first line in the page `<!doctype html>` is a doctype declaration. This tells the browser this is an HTML page.
- The `<html>` root element marks out the start and end of the document. 
- The `<head>` elements section contains information about the document. 
    - The `<title>` of the document. This is visible on the tab in a browser and used when bookmarking and the browser history. 
    - The `<meta>` element is a general purpose empty element used to add metadata. In this example, it specifies the character encoding for the document. Typically, we would add this to every document we create. 
- The `<body>` tags mark out the beginning and the end of the documents contents. Everything we want to be able on the page is placed between the two body tags. There should only ever be one set of body tags in a document.

Every HTML document we create should feature these key structural elements.
