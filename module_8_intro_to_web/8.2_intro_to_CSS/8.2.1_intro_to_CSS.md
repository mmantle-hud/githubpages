# Introduction to CSS

**Cascading Style Sheets (CSS)** define the visual appearance of documents. For example, this style sheet rule says all h1 elements should be coloured red.

**Cascading Style Sheet**

```css
h1{
    color:red;
}
```

**HTML Document**

```html
  <h1>Welcome to HTML</h1>
  <p>In this week we will be learning:</p>
```

Here's how the HTML would be displayed in the browser when the CSS is applied to the HTML document. 

<div style="all: revert; font-family: serif; display: block; margin: 1em 0; color: black; background: white; padding: 10px;">
  <h1 style="color:red">Welcome to HTML</h1>
  <p>In this week we will be learning:</p>
</div>

- HTML structures a document by specifying the meaning of the contents. 
- CSS specifies presentation, what different parts of the document should look like.

## CSS Rules
```css
body{
    background-color:LightBlue;
}
h1{
    color:red;
    font-size:50pt;
}
p{
    text-align: center;
    font-family: Arial;
}
```

CSS are made up of a number of rules. In this example there are three rules.
- Each rule has a selector and a declaration block. 
- The selector specifies which part of the HTML document we want to style
- The declaration block specifies how we want to style it.
    - Within the declaration block we have a number of declarations as property:value pairs. 

## Applying CSS
There are a number of different ways of applying CSS to a web page

1. External CSS
2. Internal CSS using the `<style>` element
3. Inline CSS using the `style` attribute

We will only look at using an external style sheet as this is the most efficient way of applying CSS. 

To use an external style sheet we place our CSS rules in a file with a _.css_ extension e.g. _style.css_.

**style.css**

```css
body{
    background-color:LightBlue;
}
h1{
    color:red;
    font-size:50pt;
}
p{
    text-align: center;
    font-family: Arial;
}
```

We then link the HTML document to the CSS file using a `<link>` element in the `<head>` of the document. 

This specifies the URL of the document, in this example `style.css` and the relationship between the HTML document and the linked file (`rel="stylesheet"`).

```html
<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <link href="style.css" rel="stylesheet">
    <title>Example HTML Document</title>
  </head>
  <body>
    <h1>Welcome to HTML</h1>
    <p>This is an example paragraph.</p>
  </body>
</html>
```
A web browser will then apply the CSS to the HTML.

<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: lightblue; padding: 10px;">
  <h1 style="background: lightblue;color:red">Welcome to HTML</h1>
  <p style="text-align:center; font-family:Arial">This is an example paragraph.</p>
</div>

## Style Sheet Properties
The power of style sheets comes through the wide range of properties that can be used
- Text-related properties
- Box Properties
- Color + background Properties
- Positioning properties
- Animation properties

The following demonstrates some of these properties

For a comprehensive reference see [https://developer.mozilla.org/en-US/docs/Web/CSS/Reference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference). 

### Text-Related Properties

There are lots of properties for adjusting text
formatting e.g. font-family, font-size, font-weight, text-decoration, letter-spacing etc.

```css
p{
    text-align: center;
    font-family: Arial, Helvetica, sans-serif;
    letter-spacing:10px;
}
```
<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: white; padding: 10px;">
  <p style="text-align:center; font-family:Arial; letter-spacing:10px">This is an example paragraph.</p>
</div>

When specifying fonts, a list of fonts is used. If the user's machine doesn't have the first font installed they can use the second font and third fonts as alternatives.

### Colours
Colour values can be specified as:
- Colour names – e.g. `red` (only a limited number are recognised)
- Hexadecimal codes – e.g. `#aa32f5`
- RGB values – e.g. `rgb(0,0,255)`

We can specify colours for text, backgrounds, borders etc.

### Box Properties
Every element in an HTML document has an 'invisible box' around it that we can style.

```css
h1{
    background-color: #31613e;
    color: white;
    border-style: solid;
    border-color: #ff0000;
    padding:30px;
    margin:40px;
}
```

<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: white; padding: 10px;">
   <h1 style="background: #31613e;color:white; border-style:solid;border-color:red;padding:30px;margin:40px">Welcome to HTML</h1>
</div>
<p></p>

- Border properties e.g. `border-style:solid;`,`border-color:red;` can make the box visible.
- `padding` is the area between the content and the border
- `margin` is the gap around the outside of the element and surrounding elements. 

### Units
We can specify the size of borders, padding, margins widths, fonts etc in a number of different ways

- Absolute sizes e.g. cm, mm, px, pt
- Relative sizes e.g. em, rem, %

Relative sizes are useful for when we want to create designs that resize for different sized displays (responsive design). 

It is considered best practice to use relative units. However, absolute sizes are easier to work with for beginners. I'd recommend starting with absolute sizes. 

## Selectors
There are lots of different ways of selecting parts of an HTML page when applying CSS. So far we have only selected using tag name e.g. 
 
```css
li{
    font-family:verdana;
}
```
We can also group tags using a comma
```css
h1, h2, h3, p{
    color:green;
}
``` 
There are others ways to select parts of the HTML document.

### The Descendent Selector

We can target elements based on which elements they are nested within. We do this with an empty space between the tag names. 

```css
h1 em{
    border:1px solid black;
}
```
This rule states that only the `<em>` elements that are nested inside
a `<h1>` will have a visible border.

```html
<h1>Product <em>Reviews</em> </h1>
<p>This product <em>broke</em></p>
```

<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: white; padding: 10px;">
    <h1 style="font-family: serif; color: black;">Product <em style="border:1px solid black;">Reviews</em></h1>
    <p>This product <em>broke</em></p>
</div>

### The `class` Selector
The class selector (`.`) is used to select a group of elements based on a name we choose. 

```css
.negative{
    color: #9b2626;
}
.positive{
    color: #269b4b;
}
```

```html
<p class="negative">This product broke the first time I used it.</p>
<p class="positive"> A great product, I'd recommend it to all my friends.</p>
<p class="negative">I'm very disappointed with this. The instructions are confusing and it breaks easily.</p>
```

<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: white; padding: 10px;">
<p class="negative" style="color: #9b2626;">This product broke the first time I used it.</p>
<p class="positive" style="color: #269b4b;"> A great product, I'd recommend it to all my friends.</p>
<p class="negative" style="color: #9b2626;">I'm very disappointed with this. The instructions are confusing
and it breaks easily.</p>
</div>

`class` is an HTML attribute. We invent the name of our classes. In this example `negative` and `positive`. We can then write CSS to target these classes. 

In real world web design, the class selector is the most commonly selector. It provides flexibility and allows us to break free of selecting by tag name. 

## The `<div>` and `<span>` elements

HTML features two elements that don't have any special meaning `<div>` and `<span>`. They are used to mark out areas of a document so we can style it using CSS. `<div>` is used for large blocks. `<span>` is used inline. 

```css
.reviews{
    border: 1px solid #222222;
    padding: 20px;
    margin:30px;
}
.negative{
    color: #9b2626;
}
.positive{
    color: #269b4b;
}
```

```html
<div class="reviews">
    <h2>Reviews</h2>
    <p class="negative">This product broke the first time I used it.</p>
    <p class="positive"> A great product, I'd recommend it to all my friends.</p>
    <p class="negative">I'm very disappointed with this. The instructions are confusing and it breaks easily.</p>
</div>
```

<div style="all: revert; font-family: serif; display: block; margin: 0em 0; color: black; background: white; padding: 10px;">
    <div class="reviews" style="border: 1px solid #222222;padding:20px;margin:30px;">
    <h2 style="font-family: serif; color: black;">Reviews</h2>
    <p class="negative" style="color: #9b2626;">This product broke the first time I used it.</p>
    <p class="positive" style="color: #269b4b;"> A great product, I'd recommend it to all my friends.</p>
    <p class="negative" style="color: #9b2626;">I'm very disappointed with this. The instructions are confusing
    and it breaks easily.</p>
    </div>
</div>

Often we will mark-up large parts of the page using a `<div>` that we can then style as a single block.
